### Open-Source Pawn Libraries (`not_*` Suite)

Standalone, documented, MIT-licensed includes for **SA-MP** and **open.mp**:

| Library | Description | Dependencies |
| :--- | :--- | :---: |
| **[not_ghost_system](https://github.com/by-not/not_ghost_system)** | Client-side Ghost NPCs & Vehicles (`not_ghost_npc`) + live Scene/Killcam Recorder (`not_ghost_recorder`). | `Pawn.RakNet`, `y_malloc` |
| **[not_vehicle_system](https://github.com/by-not/not_vehicle_system)** | All-in-one vehicle utilities: physical parts, 194 upgrades/components, SP colors, and paintjobs for all 212 models. | None (`a_samp`) |
| **[not_menu](https://github.com/by-not/not_menu)** | Interactive PlayerTextDraw menus with keyboard + mouse navigation, pagination, dynamic info box, and 3D model preview. | None (`a_samp`) |
| **[not_dialog_pages](https://github.com/by-not/not_dialog_pages)** | Zero-dependency paginated dialogs (`LIST`, `TABLIST`, `TABLIST_HEADERS`) with packed `char` memory storage. | None (`a_samp`) |
| **[not_textdraw_manager](https://github.com/by-not/not_textdraw_manager)** | Centralized TextDraw cursor state, active UI window tracking, clean ESC routing, and safe TD destruction. | None (`a_samp`) |
| **[not_notify](https://github.com/by-not/not_notify)** | Modular 5-channel visual HUD notification system with slot-based timers and automatic line wrapping. | None (`a_samp`) |
| **[not_taskbar](https://github.com/by-not/not_taskbar)** | Dynamic-height TaskBar HUD cards with sprite icons, timers, and auto-colored progress bars. | `progress2` |
| **[not_android_menu](https://github.com/by-not/not_android_menu)** | Touch-friendly clickable PlayerTextDraw menus (`SelectMenu` & `EditMenu`) tailored for SA-MP Android & PC. | None (`a_samp`) |
